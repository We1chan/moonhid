手柄实机验证

选择一个手柄，按按钮、移动摇杆，保存实际输入与解码结果。数据保留在当前页面，点击导出才写入文件。

浏览器没有原始报告描述符。本页根据浏览器可见字段生成参考描述符，明确标记来源；不恢复原始编码、嵌套集合、物理单位或 Delimiter 元数据。

：明确忽略浏览器逻辑范围、Array 映射和 Null 判定；适合浏览器元数据不完整时检查按钮与轴的原始数值。

需要 Chromium、HTTPS 或 localhost。仅接收选中手柄的 Input，不发送控制指令。

验证步骤

  1. 静置手柄后按下、松开 A。
  2. 将左摇杆移动到两端，再回中。
  3. 检查按钮和轴值是否随动作变化。
  4. 停止接收，导出最近 100 条报告；硬件拔出另行验证。
